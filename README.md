# Jessica Heusler Watercolors

A single-page React app for browsing and managing a gallery of original watercolor paintings.

## Features

- Browse paintings in a responsive gallery grid
- Click any painting to view it larger in a lightbox, with next/previous navigation
- Add new paintings through a validated form
- Remove paintings from the gallery

## Tech

- React + Vite
- React Router

## Running locally

```
npm install
npm run dev
```
